司南防火墙 SinanWAF v1.0.0

为宝塔面板打造的全功能网站防火墙（WAF），基于 Nginx/Apache 原生指令 + 日志智能分析 + 木马查杀引擎，无需第三方模块，资源占用低。

核心能力

  • 流量与访问控制：IP 黑白名单（变更即时校验并 reload 生效，白名单优先放行）、临时封禁（1 小时/24 小时/7 天自动解封）、IP 段/地区封禁、IP 粘贴提取与批量封禁（自动生成 x.x.x.0-x.x.x.255、一键复制、网段/单 IP 开关）、服务端分页搜索与批量删除、名单批量导出（TXT/CSV/JSON）、端口与协议规则、URL/UA/Referer 过滤、限速与频率限制（静态资源与自定义 URL 可豁免）、防暴力破解与 CC 攻击。
  • 安全防护：SQL 注入、XSS、文件上传与木马检测、恶意爬虫识别、敏感路径与目录扫描拦截；频率规则可按 URI 单独限速（不改站点路由）。
  • 木马扫描杀毒：MD5 黑名单 + 18 条内置特征 + 启发式加权评分，识别 WebShell / 图片马 / 免杀混淆；支持隔离恢复、白名单、误报反馈、自定义特征库、定时全量与增量扫描。
  • WAF 配置联动：Nginx/Apache 双引擎配置下发，改动前备份、nginx -t / httpd -t 校验、失败自动回滚、端口规则联动系统防火墙。
  • 日志与告警：攻击日志（每 10 分钟增量分析，行内时间入库）、可视化统计报表、Webhook/钉钉/企业微信/邮件多通道告警（含静默时段与发送历史）、日志导出与审计追溯。
  • 状态 / 威慑推送：独立 Webhook 主动汇报系统运行状态与拦截战报，支持企业微信/钉钉/通用 Webhook，Markdown 与纯文本一键切换（Markdown 适合企微内查看，纯文本可直接转发个人微信）；定时推送、阈值触发与手动推送任选。
  • 管理与交互：左侧分组导航、一键启停与宽松/标准/严格模式切换、规则测试器与下发预览、站点配置预览与下发报告、站点批量开关、统计图表与 CSV/PNG 导出、规则导入导出、快照/文件备份（可下载删除）、角色与用户映射，与宝塔站点及 Nginx/Apache 自动联动。
  • 递归自我改进：基于攻击日志自动分析特征并生成/优化规则；规则效果评估、误报率监控、超阈值自动降级与回滚、持续学习迭代。

快速开始

  • 安装后进入插件 → 防护总览，开启防火墙并选择防护模式；
  • 在站点列表中为需要防护的网站打开 WAF 开关；
  • 在 攻击日志 页查看攻击详情，可按 1 小时/24 小时/7 天/永久封禁 IP 或标记误报；
  • 在 智能优化 页管理自动生成的候选规则与回滚。
